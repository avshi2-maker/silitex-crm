# Friday report to Federica — weekly routine

Created 21/10/2026 · lives in the CRM: **📮 דוח שבועי לפדריקה** (/federica)

## How it works
1. During the week: every question for Silitex goes into the register (/federica → ➕). English, the way Federica reads it.
2. Each question has a priority (🔴 blocker / 🟠 important / 🟢 when possible), who answers (Federica, Eleonora, lab, IT, owners) and linked leads.
3. Friday: open /federica → write 2–4 highlights + next week → 📋 copy into Outlook → send to Federica (+ Eleonora).
4. Press **✅ שלחתי** — every open question is stamped "asked today"; the ticker shows how many Fridays each one has waited.
5. When Federica answers: 💬 → paste the short answer → it moves to "answered" and is thanked in the next report.
6. "My day" shows the ticker every day and turns gold on Friday.

The register is stored in Supabase (no new tables — system row `reg-silitex` in meeting_actions).
