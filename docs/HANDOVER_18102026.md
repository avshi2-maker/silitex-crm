- While wiring Cloudinary, the OpenAI key had been pasted into `CLOUDINARY_API_KEY`. `/api/field/sign` returns the Cloudinary api_key to the browser (by design), so the OpenAI key appeared in a test response in this chat.
- **Done:** old OpenAI key "Silitex" **revoked** (usage $0.00), new key **silitex2** active in Vercel `OPENAI_API_KEY`. Cloudinary key/secret corrected; upload test passed.
